# Telegram Bot Integration

## Overview

AutoZeniq integrates with the official Telegram Bot API. This connection enables businesses to route incoming customer messages sent to their Telegram Bot directly into the AutoZeniq Unified Inbox, leveraging RAG-grounded AI auto-replies or manual agent support.

---

## Technical Architecture

The Telegram integration operates using token-based authentication and secure webhook tunnels:

### Simple Explanation
To connect Telegram, the business owner creates a bot in Telegram using the `@BotFather` account and copies the "Bot Token" (a secure code). They paste this token into their AutoZeniq dashboard settings. AutoZeniq then configures the bot to instantly route all customer messages to their unified workspace.

### Technical Explanation
1.  **Token Connection**: The tenant inputs their Telegram Bot Token in the integrations UI. The backend encrypts this token at rest using `AES-256-GCM` and saves it in the database connected to the tenant's profile.
2.  **Webhook Registration**: Upon saving, the system executes an outbound POST request to Telegram's configuration API:
    `https://api.telegram.org/bot<token>/setWebhook?url=https://api.autozeniq.com/v1/integrations/telegram/webhook&secret_token=<hash>`
    The `secret_token` parameter is generated by AutoZeniq to verify webhook payload origins.
3.  **Webhook Ingestion**: Telegram delivers customer messages to the webhook endpoint. The gateway validates that the header `X-Telegram-Bot-Api-Secret-Token` matches the connection secret, before parsing the message payload (sender IDs, chat IDs, text content, attachments) and routing it to the database queue.
4.  **Send API Outbound Delivery**: Outbound messages from the inbox are delivered to the customer by making a POST request to Telegram's API endpoint `https://api.telegram.org/bot<token>/sendMessage`, including parameters for `chat_id` and message content.

## Core Features

*   **Token-Only Setup**: Integrates Telegram Bots using a single Bot Token input field.
*   **Automatic Webhook Lifecycle**: Registers webhooks automatically upon bot connection and calls `deleteWebhook` when deleted.
*   **Media Processing**: Ingests incoming images, PDF documents, and audio clips from Telegram, converting and storing them in Cloudflare R2.
*   **Inline Keyboards**: Renders quick-reply inline button options for customer navigation within the chat window.

---

## Benefits

*   **Privacy Focus**: Allows customers to interact with businesses on Telegram without sharing their phone numbers.
*   **Unified Desk**: Manages Telegram conversations alongside WhatsApp and Facebook Page streams.
*   **Rate-Limit Protection**: Manages Telegram's rate limits (30 messages/second max to chats) using Redis queue throttling (`BullMQ`).

## FAQ

### Q: How do I generate a Telegram Bot Token?
**A:** Open Telegram, search for the official `@BotFather` account, start a conversation, send the command `/newbot`, and follow the prompts to name your bot and receive the HTTP API token.

### Q: Can the AI Agent reply to Telegram messages?
**A:** Yes. Once a bot is connected, conversations default to the `ai` state, allowing the AI Agent to evaluate context and auto-reply using the RAG database.
