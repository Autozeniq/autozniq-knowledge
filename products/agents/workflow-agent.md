# AutoZeniq Workflow Agent

The **AutoZeniq Workflow Agent** is an action-oriented sub-agent of the AutoZeniq AI Agent system. It interprets conversational requests to execute transactional operations, such as creating custom checkout sessions, pulling real-time order tracking details from courier APIs, or posting outbound webhooks.

---

## User Explanation

The Workflow Agent is the "doer" in the system. While other agents talk and collect info, the Workflow Agent does actual tasks. For example, if a customer says, "Send me the bill for this product" or "Where is my order #1234?", the Workflow Agent automatically calls the storefront system to generate a payment link, or logs into the courier service to check the package status, and gives the answer directly back to the customer.

---

## Technical Specifications

The Workflow Agent acts as a mediator between the LLM's function-calling interface and internal/external APIs:

*   **Function Calling Interface**: The agent is provisioned with structured JSON schema tool definitions (similar to OpenAI function schemas or Gemini tool declarations). Examples include `create_checkout_link`, `check_order_status`, and `calculate_shipping_fee`.
*   **Execution Safety Gates**: Tool calls generated by the LLM are parsed and run through the backend API integration gateway. Before execution, the payload's `tenant_id` context is compared against the session context to block cross-tenant database access.
*   **Third-Party API Integrations**: Executes calls to configured store plugins (Shopify Graph API, WooCommerce REST API) and local shipping systems (such as Pathao, Paperfly, or custom courier APIs).
*   **Stateful Context Handover**: When a tool execution succeeds (e.g. generating a checkout URL), the agent feeds the result back into the LLM context, which then outputs a human-readable confirmation message containing the link.

---

## Use Cases

*   **Payment Link Generation**: Instantly creating and sending an invoice checkout URL to a buyer in WhatsApp when they agree to purchase.
*   **Order Tracking lookup**: Fetching and displaying the current shipping status of an order directly from the shipping API when requested.
*   **Inventory Checks**: Answering whether an item is in stock by querying the database in real-time.
