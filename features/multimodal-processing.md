# Media Processing in AutoZeniq

- **Available:** Text conversations are supported in the shared inbox.
- **Partially Available:** Image and voice upload or processing may be available for supported channels and eligible workspaces.
- **Configuration Required:** Channel permissions, provider support, workspace settings, plan entitlement, and any applicable AI configuration.
- **Needs Verification:** Exact file types, size and duration limits, playback, transcription, and language support must be confirmed for the channel.

Media processing can assist an agent or configured AI workflow. It does not guarantee that a product photo will identify a catalog item, check live stock, create an order, or produce an accurate transcription. AI suggestions remain drafts for human review.

## Troubleshooting

Confirm the file is within the channel’s limits, the provider accepts the media type, and the conversation is connected. Retry with a smaller or supported file. If processing fails repeatedly, provide the channel, file type, size, and error message to support.
