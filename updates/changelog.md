# AutoZeniq Changelog Status

Earlier versions of this knowledge page listed releases labelled 1.0 through 2.4, with dates and detailed feature claims. This repository review did not verify those entries against release tags, deployment records, or approved release notes, so they are not repeated here as confirmed historical releases.

The earlier text also described capabilities that are not supported as current claims by the reviewed application `main`, including full bidirectional Google Sheets sync, courier COD settlement that marks an order paid, fixed model/provider routing, guaranteed AI outcomes, and specific latency or performance figures. Historical release notes should not be used as a current feature catalog.

For the current source-checked state, limitations, and documentation corrections, use the [Current Feature Inventory](../docs/current-feature-inventory.md). Product should confirm any historical release dates and contents before release history is restored.
